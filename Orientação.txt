# Caso você tenha problema em compilar e executar seu código, siga as instruções abaixo:


#Passo 1: Criar/editar o tasks.json

- No VS Code, com sua pasta do projeto aberta
- Pressione Ctrl+Shift+P
- Digite e selecione "Tasks: Configure Task"
- Digite procurando por "Create tasks.json file from template" → "Others" e clique para selecionar

Isso vai abrir um arquivo .vscode/tasks.json. Apague todo o conteúdo e cole isto:

json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "Compilar e Desbloquear",
            "type": "shell",
            "command": "gcc",
            "args": [
                "${file}",
                "-o",
                "${fileDirname}/output/${fileBasenameNoExtension}.exe"
            ],
            "options": {
                "shell": {
                    "executable": "powershell.exe"
                }
            },
            "problemMatcher": ["$gcc"],
            "group": {
                "kind": "build",
                "isDefault": true
            }
        },
        {
            "label": "Desbloquear Executavel",
            "type": "shell",
            "command": "Unblock-File",
            "args": [
                "-Path",
                "${fileDirname}/output/${fileBasenameNoExtension}.exe"
            ],
            "options": {
                "shell": {
                    "executable": "powershell.exe"
                }
            },
            "dependsOn": "Compilar e Desbloquear"
        }
    ]
}

- Salve o novo código com ctrl + s


#Passo 2: Usar

Toda vez que quiser compilar (com o arquivo .c aberto e focado no editor):

- Pressione Ctrl+Shift+P
- Digite "Tasks: Run Task"
- Escolha "Desbloquear Executavel"
